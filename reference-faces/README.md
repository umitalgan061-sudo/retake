# Reference faces

The 20 named entries currently listed in this directory are not validated JPEG/PNG images. The repository audit found 36-byte `/api/images/...` reference text entries, not the original image bytes.

Do not use the current entries as face images. Place the real, consented reference photos in the local iOS app resources or import them into the app on-device.

**Privacy:** this GitHub repository is public. Do not commit personal face photographs, face embeddings, biometric templates, or other private identity data here. The local paths `/private-assets/` and `/ios/Retake/Resources/PrivateAssets/` are ignored by Git.
